# Security Policy

Only the latest commit on `main` is supported; there are no maintained release branches or backports.

To report a vulnerability, please use [GitHub private security advisories](https://github.com/hharsha98/agentfleet/security/advisories/new) rather than a public issue — this keeps the report private until a fix is out.

Expect an initial response within 5 business days.

This is a solo portfolio project, not a production service with an on-call rotation — treat response times accordingly.
